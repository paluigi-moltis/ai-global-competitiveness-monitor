Methodology & coverage notes
Index construction

Index(g,t) = Σ wᵢ·xᵢ / Σ_{available} wᵢ — every component has a user-configurable weight (config/weights.xlsx); weights are auto-normalised, missing components are excluded (not zero-filled) and remaining weights renormalised. Historical series carry the latest observation at or before each date forward (no look-ahead); the observation date is retained.

Coverage & caveats

Capability components currently draw on GPQA Diamond, MATH, AIME (OTIS Mock 2024-25), SWE-bench Verified and LiveBench. LMArena is unavailable (no public API). Spending components carry zero default weight. Download counters are cumulative levels with platform-specific semantics; shares are computed within each platform separately.

Percentile normalisation is relative: raw scores are shown on the Capabilities page. Benchmark scores are carried forward until superseded — check component freshness before interpreting short-term moves.

Static dashboard — data queried client-side from Parquet via DuckDB-Wasm. Sources: Epoch AI (CC BY 4.0), LiveBench, OpenRouter, Vercel AI Gateway (CC BY 4.0), Hugging Face, ModelScope, Ollama.
